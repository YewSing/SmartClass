# T41 — Server-side recognition from face crops (FR-402–FR-405, NFR-10, NFR-22)

## Goal
A camera device sends cropped face images to `POST /device/faces` with its own `X-Device-Key`.
The server embeds each crop with InsightFace, matches it **only against students enrolled in the
open session's class** (at or above `FACE_MATCH_THRESHOLD`), counts consecutive-frame votes per
device (`FACE_VOTE_THRESHOLD`, default 3), and on the 3rd consecutive frame records Present or
Late through `attendance_service.mark_present` (with the time and the device). A face that matches
a student who is *not* enrolled is logged, never recorded. Repeats never create a second record.

Done when: the endpoint works as below, and tests cover match, late arrival, below threshold,
not enrolled, vote counting and duplicate — including real InsightFace sample images.

**a) `embed_crop(face_app, data: bytes) -> np.ndarray | None`** (sync, runs in a thread)
1. `img = cv2.imdecode(np.frombuffer(data, np.uint8), cv2.IMREAD_COLOR)`; `None` → return `None`.
2. If `max(h, w) < 320`: resize so the longer side is 320 (`cv2.INTER_LINEAR`). Device crops are small; the detector (det_size 640) misses tiny faces.
3. `faces = [f for f in face_app.get(img) if f.normed_embedding is not None]`.
4. If empty: pad the image on every side by `max(h, w) // 2` px of black (`cv2.copyMakeBorder(..., cv2.BORDER_CONSTANT, value=(0,0,0))`) and run `face_app.get` again (a tight crop has no context for the detector).
5. Still empty → `None`. Otherwise return the `normed_embedding` of the largest face (by bbox area).
Never write the bytes or the image to disk (NFR-01).

**b) `async def find_open_session(db, camera: Camera) -> AttendanceSession | None`**
The open session for this device's room:
```python
q = (select(AttendanceSession)
     .outerjoin(ClassOccurrence, AttendanceSession.occurrence_id == ClassOccurrence.id)
     .where(AttendanceSession.status == "open",
            or_(AttendanceSession.camera_id == camera.id,
                and_(AttendanceSession.camera_id.is_(None), ClassOccurrence.room == camera.room)))
     .order_by(AttendanceSession.opened_at.desc().nullslast(), AttendanceSession.id.desc())
     .limit(1))
```
The second branch covers a session opened before the room's device was registered (its
`camera_id` is NULL). A backup laptop webcam (FR-409) runs with the room's own device key, so it
is the same device to the server — write that in the docstring. A NULL-camera session in
**another** room is never used (unlike `/internal/face-match`; that endpoint is left as is).

**c) `@dataclass class Match: outcome: str; student_id: int | None; similarity: float | None`**
and `async def match_embedding(db, embedding: np.ndarray, occurrence_id: int | None) -> Match`:
- `vec = str([float(x) for x in embedding])`.
- Enrolled best (FR-403, only the session's class):
  ```sql
  SELECT fe.student_id, (1 - (fe.embedding <=> CAST(:vec AS vector))) AS similarity
  FROM face_embeddings fe
  JOIN enrollments e ON e.student_id = fe.student_id AND e.occurrence_id = :occ
  ORDER BY fe.embedding <=> CAST(:vec AS vector) LIMIT 1
  ```
  (check the enrolment table name in `app/models/class_.py` `Enrollment.__tablename__`.)
  If `occurrence_id` is None skip this query (no enrolled row).
- If a row and `similarity >= settings.FACE_MATCH_THRESHOLD` → `Match("matched", student_id, sim)`.
- Else the global best (same SQL without the JOIN). If its similarity `>= threshold` (so it is a
  student not enrolled in this class) → `logger.info("Face matched student %s, who is not enrolled in session %s's class (similarity %.3f); not recorded", sid, ...)` is done by the caller (it knows session/device), return `Match("not_enrolled", that_student_id, sim)`.
- Else `Match("below_threshold", None, enrolled_sim if an enrolled row existed else None)`.

**d) Votes (FR-404)**
```python
@dataclass
class _DeviceVotes:
    session_id: int
    last_at: datetime
    counts: dict[int, int] = field(default_factory=dict)   # students.id → consecutive frames

_votes: dict[int, _DeviceVotes] = {}   # camera.id → state

def reset_votes() -> None:
    _votes.clear()

def vote(camera_id: int, session_id: int, student_ids: set[int], now: datetime) -> dict[int, int]:
    """Count one frame. Returns votes per student in `student_ids` after this frame.
    A student missing from a frame starts again from 0; so does everyone when the session
    changes or when the last frame is more than FACE_VOTE_MAX_GAP_SECONDS old.
    A student who reaches FACE_VOTE_THRESHOLD is removed from the state (the caller records them)."""
```
Rules, exactly:
- `state = _votes.get(camera_id)`; if `None`, or `state.session_id != session_id`, or `now - state.last_at > timedelta(seconds=settings.FACE_VOTE_MAX_GAP_SECONDS)` → new `_DeviceVotes(session_id, now)`.
- `new_counts = {sid: state.counts.get(sid, 0) + 1 for sid in student_ids}` (students not in this frame are dropped).
- Result = `new_counts`; then remove those with count `>= settings.FACE_VOTE_THRESHOLD` from `new_counts`; `state.counts = new_counts`; `state.last_at = now`; `_votes[camera_id] = state`.
- **No `await` inside `vote`** — it is a plain function, so two requests can't interleave inside it.

**e) `async def recognise_frame(db, face_app, camera: Camera, session: AttendanceSession, crops: list[bytes]) -> list[dict]`**
1. `embeddings = await asyncio.to_thread(lambda: [embed_crop(face_app, c) for c in crops])`.
2. `now = session_schedule.clock()` — **call through the module** (`session_schedule.clock()`), never `from ... import clock`, or tests can't patch it.
3. `recorded = {sid: status for sid, status in (await db.execute(select(AttendanceRecord.student_id, AttendanceRecord.status).where(AttendanceRecord.session_id == session.id))).all()}`.
4. For each crop index `i`:
   - embedding `None` → result `{"index": i, "outcome": "no_face"}`.
   - else `m = await match_embedding(db, emb, session.occurrence_id)`:
     - `not_enrolled` → log (logger.info with student id, session id, `camera.device_id`, similarity) and result `{"outcome": "not_enrolled", "similarity": m.similarity}` (no `student_id`).
     - `below_threshold` → `{"outcome": "below_threshold", "similarity": m.similarity}`.
     - `matched` and `m.student_id in recorded` → `{"outcome": "already_recorded", "student_id", "similarity", "status": recorded[sid]}`.
     - `matched` otherwise → remember `(i, sid, sim)` as a candidate.
5. Voting: if **no crop produced an embedding** (all `no_face`), do not call `vote` (the frame is ignored; it doesn't reset anyone). Otherwise `counts = vote(camera.id, session.id, {candidate sids}, now)`. The same student in two crops of one frame counts once.
6. For each candidate crop: `n = counts[sid]`. If `n < FACE_VOTE_THRESHOLD` → `{"outcome": "voting", "student_id", "similarity", "votes": n}`.
   If `n >= threshold` and the student isn't recorded yet in this request:
   ```python
   try:
       async with db.begin_nested():
           record, was_new = await attendance_service.mark_present(session.id, sid, db, now=now, camera_id=camera.id)
   except IntegrityError:   # NFR-22: another path recorded them at the same moment
       record, was_new = (await db.execute(select(AttendanceRecord).where(...session, student...))).scalar_one(), False
   ```
   `was_new` → load the student (`select(Student).options(selectinload(Student.user)).where(Student.id == sid)`), `await attendance_service.broadcast_attendance_update(session.id, record, student.user.name, student.matric_no, db)`, result `{"outcome": "recorded", "student_id", "similarity", "votes": n, "status": record.status}`; not new → `already_recorded` with `record.status`.
   If the same student appears in a second crop of the same frame after being recorded, that crop is `already_recorded`.
   Keep a local `done: dict[int, str]` (sid → status) so the second crop sees it.
7. Return results sorted by `index`.

5. `results = await recognition_service.recognise_frame(db, face_app, camera, session, datas)`; return `{"session_id": session.id, "results": results}`.

## Traps
- **Clock:** call `session_schedule.clock()` through the module inside `recognise_frame`; a `from app.services.session_schedule import clock` breaks every time-based test.
- **Embedding patch:** in file A patch `recognition_service.embed_crop` (the module attribute), and make `recognise_frame` call `embed_crop` by its module-level name so the patch takes effect (a lambda inside `to_thread` that calls `embed_crop(...)` looks the name up at call time — fine).
- **Only enrolled students count** (FR-403): the match query must JOIN `enrollments` on the session's `occurrence_id`. Don't reuse the old global-nearest-then-check approach of `/internal/face-match`: with two lookalikes, the global nearest may be an outsider while an enrolled student is above threshold.
- **Never change an existing record** (NFR-22, T30 rule): `already_recorded` covers any status, including a lecturer's `excused`/`absent` override. Don't vote for students who already have a record.
- **No await inside `vote()`**; keep the vote update synchronous.
- A frame where every crop is `no_face` must not reset votes; any frame with at least one embedding does (students not matched in it drop to 0).
- `student_id` is not returned for `not_enrolled` / `below_threshold`; no names/matric numbers go to the device.
- Keep `/internal/face-match`, `/internal/face-review`, `/internal/active-session` and `face_worker/` working — T42 replaces the worker. Don't edit their tests.
- Crops are never saved (NFR-01). Storing unmatched crops is T43, not this task.
- Don't touch Shino's modules (`routers/analytics.py` etc.).
- Never print or read `backend/.env`; never commit face images.
- Never weaken or skip an existing test. If an existing test fails because of the new `camera_id` column, fix the code, not the test.
