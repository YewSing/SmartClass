- `backend/tests/test_llm_fake.py` — a through-API test for fake summary + study tools.
- `mobile/student/e2e/study-tools.yaml` — the Maestro flow.

## Approach
The endpoints already exist (T85 summaries, T86 study tools). The screen calls them with a typed
topic (no student-facing material list exists, so "topic" is the input). Results:
- summary/study guide → `MarkdownText` + the same citation chips as the chat (openable source);
- flashcards → a tappable card that flips front/back;
- practice questions → options; picking one reveals correct/not-quite and the explanation.

## Edge cases
- A topic the materials don't cover → the API labels it general knowledge (shown as a tag for
  summaries; flashcards/questions come back empty and show "No … for this topic.").
- The fake LLM must return valid JSON for study tools, or the E2E hits the 502 retry path — so
  `fake_chat` detects the JSON prompt by `"Reply with a single JSON object"` and returns canned
  flashcards / questions (citation 1).
