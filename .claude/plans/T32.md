# T32 — Attendance rate + history (FR-307–FR-309)

## Goal
Give M3 one place that calculates attendance rates, and two read endpoints built on it:
- **Rate** (FR-308, decision T00d): `rate = (present + late) ÷ (closed sessions − excused)` per student per course, as a percentage (0–100, 1 decimal). Late counts as attended. Excused sessions are left out of the denominator. When the denominator is 0 (no closed sessions, or every closed session excused) the rate is `null`, never 0 and never a division error.
- Status counts (`present`, `late`, `excused`, `absent`) are returned with every rate.
- **Student endpoint** (FR-309): the logged-in student's rate + counts per course, plus the session-by-session history for that course.
- **Lecturer endpoint**: per-student rates + counts for one class the lecturer teaches.

Done when: the formula above is implemented in one service, both endpoints exist, and the db tests below pass, including the zero-closed-sessions and every-session-excused cases. `bash scripts/check.sh` passes.

### 1. New `backend/app/services/attendance_stats.py`
Module docstring: `"""Attendance rate and history (FR-307–FR-309). One formula for every reader (M3 screens, T33 reports, T37's read interface for M7)."""`

```python
from dataclasses import dataclass, field
from datetime import date

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy.orm import selectinload

from app.models.attendance import AttendanceRecord, ATTENDED_STATUSES
from app.models.class_ import ClassOccurrence, Enrollment
from app.models.session import AttendanceSession
from app.models.user import Student

HISTORY_SESSION_STATUSES = ("open", "closed")  # scheduled / cancelled / needs_confirmation are not shown


@dataclass
class StatusCounts:
    present: int = 0
    late: int = 0
    excused: int = 0
    absent: int = 0

    def add(self, status: str) -> None:
        setattr(self, status, getattr(self, status) + 1)

    @property
    def closed_sessions(self) -> int:
        return self.present + self.late + self.excused + self.absent

    @property
    def attended(self) -> int:
        return self.present + self.late

    @property
    def counted_sessions(self) -> int:
        return self.closed_sessions - self.excused   # Excused is left out (FR-308, decision T00d)

    @property
    def rate(self) -> float | None:
        """(present + late) ÷ (closed − excused) as a percentage, 1 decimal; None when nothing counts."""
        if self.counted_sessions == 0:
            return None
        return round(self.attended / self.counted_sessions * 100, 1)


def session_date(sess: AttendanceSession) -> date | None:
    """The MYT date of the class: class_date, else opened_at's date, else starts_at's date."""
    if sess.class_date:
        return sess.class_date
    when = sess.opened_at or sess.starts_at
    return when.date() if when else None
```

Then two async functions. Both use **a fixed number of queries** (no query per session or per student):

```python
async def student_course_history(db: AsyncSession, student_id: int) -> list[dict]:
```
1. Load the occurrences the student is enrolled in: `select(ClassOccurrence).options(selectinload(ClassOccurrence.course)).join(Enrollment, Enrollment.occurrence_id == ClassOccurrence.id).where(Enrollment.student_id == student_id)`.
2. If none, return `[]`.
3. Load the sessions of those occurrences with `status IN HISTORY_SESSION_STATUSES`.
4. Load this student's records for those session ids: `select(AttendanceRecord).where(AttendanceRecord.student_id == student_id, AttendanceRecord.session_id.in_(ids))` into a `{session_id: record}` dict. Skip the query when there are no sessions.
5. Group by `occ.course_id`, one entry per course, sorted by `course.code`. For each session:
   - `closed`: `status = rec.status if rec else "absent"`; `counts.add(status)`.
   - `open`: `status = rec.status if rec else "not_recorded"`; **not counted**.
   - History item dict: `{"session_id", "occurrence_id", "class_type": occ.type, "class_label": occ.label, "date": session_date(sess), "starts_at": sess.starts_at or sess.opened_at, "session_status": sess.status, "status": status, "detected_at": rec.detected_at if rec else None, "overridden": bool(rec and rec.override_by)}`.
   - Sort each course's history newest first by `(date or date.min, starts_at or datetime.min)` descending.
6. Each course dict: `{"course_id", "course_code", "course_name", "counts": counts, "sessions": [...]}`. Courses the student is enrolled in that have no sessions are **still returned**, with zero counts, `rate` None and empty sessions.

```python
async def class_student_rates(db: AsyncSession, occurrence_id: int) -> list[dict]:
```
1. Enrolled students of the occurrence (with `selectinload(Student.user)`), ordered by `Student.matric_no`, like `get_session_attendance`.
2. Closed session ids of the occurrence: `select(AttendanceSession.id).where(occurrence_id == ..., status == "closed")`.
3. All records for those sessions in one query; build `{(session_id, student_id): status}`.
4. For each student, for each closed session: `counts.add(lookup.get((sid, stu.id), "absent"))`.
5. Return `[{"student_id", "matric_no", "name", "counts": counts}]`, and also the closed session count via a second return value: make the signature `-> tuple[int, list[dict]]` returning `(len(closed_ids), rows)`.

Only `closed` sessions count. `open`, `scheduled`, `needs_confirmation` (FR-317: nobody is absent until confirmed) and `cancelled` never count. After `confirm(held=True)` a session is `closed` and counts; after `held=False` it is `cancelled` and doesn't.

### 2. New `backend/app/schemas/attendance_stats.py`
```python
from datetime import date, datetime
from typing import Optional
from pydantic import BaseModel


class AttendanceCountsOut(BaseModel):
    present: int
    late: int
    excused: int
    absent: int
    closed_sessions: int      # present + late + excused + absent
    counted_sessions: int     # closed_sessions - excused (the rate's denominator)
    rate: Optional[float]     # 0.0–100.0, 1 decimal; null when counted_sessions == 0


class StudentSessionHistoryOut(BaseModel):
    session_id: int
    occurrence_id: int
    class_type: str           # LECTURE | TUTORIAL
    class_label: Optional[str] = None
    date: Optional[date] = None
    starts_at: Optional[datetime] = None
    session_status: str       # open | closed
    status: str               # present | late | excused | absent | not_recorded (open session only)
    detected_at: Optional[datetime] = None
    overridden: bool = False


class StudentCourseAttendanceOut(AttendanceCountsOut):
    course_id: int
    course_code: str
    course_name: str
    sessions: list[StudentSessionHistoryOut]


class ClassStudentRateOut(AttendanceCountsOut):
    student_id: int
    matric_no: str
    name: str


class ClassAttendanceRatesOut(BaseModel):
    occurrence_id: int
    course_code: str
    course_name: str
    closed_sessions: int
    students: list[ClassStudentRateOut]
```
Name the field `date` in the Pydantic model with `from datetime import date as date_` if Pydantic complains about the field shadowing the type. Use `date_` for the annotation: `date: Optional[date_] = None`.

Add a helper in the service or router: `def counts_out(c: StatusCounts) -> dict` returning the seven `AttendanceCountsOut` fields, so both endpoints build the same shape.
