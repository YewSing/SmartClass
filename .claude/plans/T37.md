- attendance **records** per course and per student,
- attendance **rates** (FR-308: `(present + late) ÷ (closed − excused)`, `None` when the denominator is 0),
- **consecutive absences** per student per course (for M7's rule-based at-risk alerts).

## Changes

### 1. New `backend/app/services/attendance_read.py`

Module docstring:
```
"""Read interface for Module 7, Learning Analytics (FR-313). Documented in docs/interfaces.md.

Rules (same as the student app and lecturer reports, FR-308):
- Only closed sessions count. Open, scheduled, cancelled and needs_confirmation sessions are left out.
- A student enrolled in a class with no record in one of its closed sessions is absent.
- Late counts as attended; Excused is left out of the rate.
- No permission checks here: the caller (an M7 endpoint) must check the user may see the course (NFR-04).
Returned objects are frozen dataclasses; fields may be added later but are never renamed or removed.
"""
```

Imports: `dataclass` from dataclasses; `date, datetime`; `select`; `AsyncSession`; `selectinload`; `AttendanceRecord` from `app.models.attendance`; `ClassOccurrence, Enrollment` from `app.models.class_`; `AttendanceSession` from `app.models.session`; `Student` from `app.models.user`; `REPORT_SESSION_STATUSES, StatusCounts, session_date` from `app.services.attendance_stats`.

`__all__ = ["AttendanceRow", "AttendanceRate", "AbsenceStreak", "course_records", "student_records", "course_rates", "student_rates", "consecutive_absences", "absence_streak"]`

#### Dataclasses (all `@dataclass(frozen=True)`)

```python
class AttendanceRow:
    """One student's status in one closed session."""
    session_id: int
    occurrence_id: int
    class_type: str            # LECTURE | TUTORIAL
    class_label: str | None
    course_id: int
    course_code: str
    student_id: int            # students.id
    matric_no: str
    name: str
    date: date | None          # MYT date of the class (session_date)
    starts_at: datetime | None # sess.starts_at or sess.opened_at
    status: str                # present | late | excused | absent
    detected_at: datetime | None
    overridden: bool           # a lecturer changed it (override_by set)

class AttendanceRate:
    """One student's counts and rate for one course (all its classes together)."""
    student_id: int
    matric_no: str
    name: str
    course_id: int
    course_code: str
    course_name: str
    present: int
    late: int
    excused: int
    absent: int
    closed_sessions: int
    counted_sessions: int      # closed_sessions - excused
    rate: float | None         # percentage 0-100, 1 decimal; None when counted_sessions == 0

class AbsenceStreak:
    """Consecutive absences of one student in one course."""
    student_id: int
    matric_no: str
    name: str
    course_id: int
    course_code: str
    current: int               # absences in a row up to the latest closed session (0 if they last attended)
    longest: int               # longest run of absences so far
    last_attended: date | None # date of the latest present/late session; None if never
```

#### Pure helper (public, unit-testable)
```python
def absence_streak(statuses: list[str]) -> tuple[int, int]:
    """(current, longest) absence run over statuses ordered oldest first.
    absent adds 1; present/late reset the current run to 0; excused is skipped (neither breaks nor extends a run)."""
```
Loop: `if s == "absent": current += 1; longest = max(longest, current)` · `elif s in ATTENDED_STATUSES: current = 0` · excused → `continue`. Import `ATTENDED_STATUSES` from `app.models.attendance`.

#### Private core loader
```python
@dataclass
class _Loaded:
    students: dict[int, Student]                 # students.id → Student (user loaded)
    occurrences: dict[int, ClassOccurrence]      # occurrence id → occurrence (course loaded)
    enrolled: set[tuple[int, int]]               # (student_id, course_id) pairs
    rows: list[AttendanceRow]

async def _load(db, *, course_id: int | None = None, student_id: int | None = None,
                from_date: date | None = None, to_date: date | None = None) -> _Loaded:
```
Steps:
1. If `from_date and to_date and from_date > to_date`: `raise ValueError("from_date must be on or before to_date")`.
2. Enrolments: `select(Enrollment.student_id, Enrollment.occurrence_id).join(ClassOccurrence, ClassOccurrence.id == Enrollment.occurrence_id)`, add `.where(ClassOccurrence.course_id == course_id)` if given, `.where(Enrollment.student_id == student_id)` if given. Build `enrolled_by_occ: dict[int, list[int]]` (occurrence → student ids).
3. If no enrolments: return empty `_Loaded({}, {}, set(), [])`.
4. Load occurrences: `select(ClassOccurrence).options(selectinload(ClassOccurrence.course)).where(ClassOccurrence.id.in_(enrolled_by_occ))`. Load students: `select(Student).options(selectinload(Student.user)).where(Student.id.in_(all student ids))`.
5. `enrolled = {(sid, occ.course_id) for occ_id, sids in enrolled_by_occ.items() for sid in sids}` (use the loaded occurrences for course_id).
6. Closed sessions: `select(AttendanceSession).where(AttendanceSession.occurrence_id.in_(occurrence ids), AttendanceSession.status.in_(REPORT_SESSION_STATUSES))`. Filter in Python by `session_date(sess)` exactly like `class_report` does (a session with `None` date is dropped when either bound is set; bounds inclusive).
7. Records: if any sessions, `select(AttendanceRecord).where(AttendanceRecord.session_id.in_(ids))`, plus `.where(AttendanceRecord.student_id == student_id)` if given. `lookup = {(rec.session_id, rec.student_id): rec}`.
8. For each kept session, for each student id in `enrolled_by_occ[sess.occurrence_id]` (only students enrolled in **that** occurrence): `rec = lookup.get(...)`; build `AttendanceRow(status=rec.status if rec else "absent", detected_at=rec.detected_at if rec else None, overridden=bool(rec and rec.override_by), date=session_date(sess), starts_at=sess.starts_at or sess.opened_at, class_type=occ.type, class_label=occ.label, course_code=occ.course.code, name=student.user.name, ...)`.
9. Sort rows by `(r.date or date.min, r.starts_at or datetime.min, r.session_id, r.matric_no)` — oldest first, then matric.

#### Public functions (all `async`, first arg `db: AsyncSession`)
```python
async def course_records(db, course_id: int, from_date: date | None = None,
                         to_date: date | None = None) -> list[AttendanceRow]:
    """Every enrolled student's status in every closed session of the course (all its classes),
    oldest session first, then by matric no. Dates are inclusive. ValueError if from_date > to_date."""
    return (await _load(db, course_id=course_id, from_date=from_date, to_date=to_date)).rows

async def student_records(db, student_id: int, course_id: int | None = None,
                          from_date: date | None = None, to_date: date | None = None) -> list[AttendanceRow]:
    """One student's status in every closed session of the classes they are enrolled in,
    optionally for one course; oldest first."""

async def course_rates(db, course_id: int, from_date=None, to_date=None) -> list[AttendanceRate]:
    """Counts and rate per enrolled student for one course, ordered by matric no.
    Students with no closed sessions are included with rate None."""

async def student_rates(db, student_id: int, from_date=None, to_date=None) -> list[AttendanceRate]:
    """Counts and rate per course for one student, ordered by course code (courses with no
    closed sessions included, rate None)."""

async def consecutive_absences(db, course_id: int, min_current: int = 0) -> list[AbsenceStreak]:
    """Absence streaks of every enrolled student in one course, keeping those with current >= min_current,
    ordered by current (highest first), then matric no."""
```
Rates: one private `_rates(loaded) -> list[AttendanceRate]`: for every `(student_id, course_id)` in `loaded.enrolled`, a `StatusCounts()`; for each row `counts[(row.student_id, row.course_id)].add(row.status)`. Build `AttendanceRate` with `present/late/excused/absent` from counts and `closed_sessions`, `counted_sessions`, `rate` from the `StatusCounts` properties. Course code/name come from any loaded occurrence of that course (build `courses = {occ.course_id: occ.course for occ in loaded.occurrences.values()}`). `course_rates` sorts by `matric_no`; `student_rates` sorts by `course_code`.

Streaks: `consecutive_absences` calls `_load(db, course_id=course_id)`, groups row statuses per student in row order (already oldest first), computes `absence_streak(...)`, `last_attended` = date of the last row whose status is in `ATTENDED_STATUSES`. Every enrolled student appears (no rows → `current=0, longest=0, last_attended=None`). Filter `current >= min_current`, sort by `(-current, matric_no)`.

Note: a student enrolled in both the lecture and a tutorial of one course has both classes' sessions merged by date in the course streak — intended (it matches how `student_course_history` groups by course).
