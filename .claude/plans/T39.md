# T39 [UI] Student app: attendance rate + history per course

## Goal
The student app's Attendance tab shows, per course, the attendance rate, the four status counts
(Present, Late, Excused, Absent) and the session list with each session's status, all from T32's real
endpoint `GET /student/me/attendance/courses`. The app stops using Shino's `/student/me/attendance` and
`/student/me/attendance/summary` (they count only `present`, see PROGRESS T32 "Next").
Done when: that screen works from the real API, and a Maestro flow signs in as `student4`, opens
Attendance and checks a seeded course's rate (66.7%) and counts.

## Existing work
- API (T32, no change needed): `backend/app/routers/attendance_stats.py` `GET /student/me/attendance/courses`
  → `list[StudentCourseAttendanceOut]` (`backend/app/schemas/attendance_stats.py`):
  `{course_id, course_code, course_name, present, late, excused, absent, closed_sessions, counted_sessions,
  rate (float 1 decimal | null), sessions: [{session_id, occurrence_id, class_type (LECTURE|TUTORIAL),
  class_label|null, date "YYYY-MM-DD"|null, starts_at naive MYT ISO|null, session_status (open|closed),
  status (present|late|excused|absent|not_recorded), detected_at naive MYT ISO|null, overridden}]}`.
  Courses sorted by code; sessions newest first. Times are **naive Malaysia time** — never pass them to
  `new Date()` (T38 decision: shifts on a non-MYT phone); read the digits.
- Student app today: `mobile/student/src/screens/Attendance.jsx` + `AttSessionDetail.jsx` render
  old shapes (variants `present/absent/unid/pending`) built by `sessionToAttItem`, `getAttendanceSummary`,

  `attendanceGroups`, `loadAttendanceSummary`, `loadAttendanceGroups` in
  `mobile/student/src/context/StudentContext.jsx`. Nothing else uses them (checked with grep).
- Naive-time helpers to copy (not import — separate app): `mobile/lecturer/src/services/attendance.js`
  `parseLocal`, `hhmm`, `dayMonth`, `dateLabel` (lines ~55-105).
- Pure-helper + `node --test` pattern: `mobile/student/src/services/faceEnrolment.js` / `.test.js`
  (no React Native imports in the helper file; `npm test` runs `src/**/*.test.js`, and check.sh runs it).
- `Badge` (`mobile/student/src/components/Badge.jsx`) variants: blue, green, red, orange, yellow, gray.
- E2E seed pattern: `backend/scripts/e2e_face_review.py` (`seed`/`clean` async functions taking a

### 1. `backend/scripts/e2e_student_attendance.py` (new)
Docstring like `e2e_face_review.py`: "Test data for the student attendance E2E flow (T39): a local course
E2E039 with four closed sessions, one per status, for one student." Usage lines for `seed`/`clean`.
- Constants: `COURSE_CODE = "E2E039"`, `COURSE_NAME = "E2E Attendance Test"`,
  `STATUSES = ["present", "late", "excused", "absent"]`,
  `DATES = [date(2026, 10, 5), date(2026, 10, 12), date(2026, 10, 19), date(2026, 10, 26)]` (Mondays;
  status i goes with date i, so newest (26 Oct) is `absent`, oldest (5 Oct) `present`).
- `async def clean(db: AsyncSession) -> None`: find `Course` by code `E2E039`; if none return. Get its
  occurrence ids; session ids of those occurrences; delete `AttendanceRecord` (session_id in ids),
  `AttendanceSession` (ids), `Enrollment` (occurrence_id in occ ids), `ClassOccurrence` (ids), the
  `Course`; commit. Use `sqlalchemy.delete`, guard empty `in_` lists.
- `async def seed(db: AsyncSession, student_id: int, lecturer_id: int) -> int`: `await clean(db)`; add
  `Course(code=COURSE_CODE, name=COURSE_NAME)` (moodle_course_id stays NULL), flush; one
  `ClassOccurrence(course_id=…, type="LECTURE", day_of_week="Mon", start_time="08:00", end_time="10:00",
  room="E2E Room", lecturer_id=lecturer_id)`, flush; `Enrollment(student_id, occurrence_id)`; for each
  (status, d) a `AttendanceSession(occurrence_id, lecturer_id, status="closed", source="manual",
  class_date=d, opened_at=datetime(d, 8:00), starts_at=datetime(d, 8:00), ends_at=datetime(d, 10:00),
  closed_at=datetime(d, 10:00))` — leave all `moodle_*` columns NULL so the Moodle sync never sends them;
  flush; `AttendanceRecord(session_id, student_id, status=status, detected_at=datetime(d, 8, 5) for
  present, datetime(d, 8, 25) for late, None for excused/absent)`. Commit, return course id.
  All datetimes naive (MYT), like the rest of the DB.
- `async def _main(action, email)`: resolve `Student` joined to `User` by email (copy from
  `e2e_face_review._main`; same "Sync Moodle or sign them in once first" exit message). For `seed`, take
  `lecturer_id = await db.scalar(select(Lecturer.id).order_by(Lecturer.id).limit(1))`; exit with a clear
  message if None. `clean` needs no student. Print what was done. `await engine.dispose()` at the end.
- argparse: `action` in `seed|clean`, `--student` (default `student4@example.com`).
- `sys.path.insert` line as in the other scripts.
