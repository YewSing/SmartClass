# T29 — Sessions open from the class schedule (FR-301, FR-315–FR-317)

## Goal
A background job opens each class's attendance session `SESSION_EARLY_OPEN_MINUTES` (default 15) before its
scheduled start and closes it at its scheduled end, once per class date, in Malaysia time (naive MYT
datetimes, as everywhere else: `app.core.timezone.now_myt`). Sessions store their effective start and end.
The lecturer can:
- set the weekly schedule (day, start, end, room) of a class they teach, or clear it (no schedule);
- for one class date, before or during it: change the time, start now, end early, extend, or cancel.
Each of these is audited and none changes the weekly schedule. A class with no schedule never opens by
itself but can be started manually. A session that reaches its end with no attendance records and no
lecturer action becomes `needs_confirmation` (nobody marked Absent; Moodle sync, built in T35, only ever
runs for `closed`) until the lecturer confirms held / not held. Every time-dependent case is tested with a
controlled clock.

Rules (implement exactly):
- **R1 – one row per scheduled class date.** A session row with `source="schedule"` is "the class on
  `class_date`". The job never creates a second one (partial unique index backs this up).
- **R2 – job opens.** For each occurrence with `has_schedule` and `lecturer_id` not null, for `d` in
  `{now.date(), now.date() + 1 day}` (the +1 covers starts just after midnight): if `scheduled_times(occ, d)`
  gives `(s, e)` and `s - early() <= now < e`, and no `source="schedule"` row exists for `(occ.id, d)`, and no
  session of that occurrence has `status == "open"` → insert `AttendanceSession(occurrence_id, lecturer_id=occ.lecturer_id,
  camera_id=camera_id_for_room(occ.room), class_date=d, starts_at=s, ends_at=e, source="schedule",
  status="open", opened_at=now)`.
  Also: every row with `status == "scheduled"` and `starts_at - early() <= now < ends_at`, and no other open
  session for that occurrence → `status="open"`, `opened_at=now`, `camera_id=camera_id_for_room(occ.room)`.
- **R3 – job closes.** Every `status == "open"` row with `ends_at` not null and `ends_at <= now`:
  - if it has ≥ 1 `AttendanceRecord` **or** `lecturer_action_at` is not null → `close_session(id, db, now)`
    (marks absent, `status="closed"`, `closed_at=now`);
  - else → `status="needs_confirmation"`, `closed_at=now`, no records written.
  Every `status == "scheduled"` row with `ends_at <= now` (server was down for the whole class) →
  `needs_confirmation`, `closed_at=now`.
- **R4 – lecturer action** (`lecturer_action_at = now`) is set by: start now, extend, and a time change while
  the session is `open`. A time change or cancel **before** the class is not a lecturer action. Overrides
  already create an `AttendanceRecord`, so they count through the record check. Unidentified faces
  (`FaceReviewEntry`) are **not** recognitions.
- **R5 – no schedule** (`has_schedule` False): the job ignores the occurrence; start now works.
- **R6** – the job never touches `ClassOccurrence` columns; one-class changes only edit the session row.

Functions:
```python
@dataclass
class TickReport:
    opened: list[int] = field(default_factory=list)
    closed: list[int] = field(default_factory=list)
    needs_confirmation: list[int] = field(default_factory=list)

async def tick(db: AsyncSession, now: datetime | None = None) -> TickReport:
    """One pass of R2 then R3. Flushes, does not commit. now defaults to clock()."""
```
Order inside `tick`: close first (R3), then open (R2), so a class that ends at 10:00 frees the
"one open per occurrence" slot for a class starting at 10:00 on the same pass (matters for the 00:00–23:59
dev class too).

```python
async def session_scheduler_loop() -> None:
    """Background task started in main.py; SESSION_SCHEDULER_INTERVAL_SECONDS <= 0 disables it."""
    if settings.SESSION_SCHEDULER_INTERVAL_SECONDS <= 0:
        return
    while True:
        try:
            async with AsyncSessionLocal() as db:
                try:
                    report = await tick(db)
                    await db.commit()
                except Exception:
                    await db.rollback()
                    raise
            for sid in report.closed + report.needs_confirmation:
                counts = ...  # new short-lived session: get_session_counts(sid, db)
                await manager.broadcast(sid, {"event": "session_closed", "status": <"closed"|"needs_confirmation">,
                                              "counts": counts, "final": True})
        except asyncio.CancelledError:
            raise
        except Exception as exc:
            log.warning("Session scheduler failed: %s", exc.__class__.__name__)
        await asyncio.sleep(settings.SESSION_SCHEDULER_INTERVAL_SECONDS)
```

Lecturer operations (also in `session_schedule.py`; routers call them; each raises `HTTPException` with the
codes below; each writes its audit log with `write_log(db, actor_user_id, ACTION, "attendance_session", session.id, old, new)`
where old/new are dicts of ISO strings / status). All take `now: datetime` from the router (`clock()`).

1. `async def set_weekly_schedule(db, occ, body, actor) -> ClassOccurrence` — audit `CLASS_SCHEDULE_SET`,
   `target_type="class_occurrence"`, `target_id=occ.id`, old/new = `{"day_of_week","start_time","end_time","room"}`.
   Existing session rows are not changed.
2. `async def start_now(db, occ, lec, now, duration_minutes: int | None) -> AttendanceSession`:
   - an `open` session of this occurrence exists → 409 "A session is already open for this occurrence"
     (same text as today).
   - today = `now.date()`; `row` = `source="schedule"` row for `(occ.id, today)`.
   - length = `timedelta(minutes=duration_minutes)` if given, else the scheduled length (end − start) if
     `has_schedule`, else `settings.SESSION_DEFAULT_MINUTES`.
   - if `row` and `row.status == "scheduled"` → open it: `starts_at=now`,
     `ends_at = now + length if duration_minutes else (row.ends_at if row.ends_at > now else now + length)`.
   - elif no `row` and `scheduled_times(occ, today)` gives `(s, e)` with `now < e` → create the
     `source="schedule"` row for today: `starts_at=now`, `ends_at = now + length if duration_minutes else e`.
   - else → new `source="manual"` row, `class_date=today`, `starts_at=now`, `ends_at=now+length`.
   - In all branches: `status="open"`, `opened_at=now`, `lecturer_id=lec.id`,
     `camera_id=camera_id_for_room(occ.room)`, `lecturer_action_at=now`. Audit `SESSION_START_NOW`
     new = `{"starts_at","ends_at","source"}`.
   - Note: a `row` that is `closed/needs_confirmation/cancelled` falls through to the manual branch
     (keeps `test_closed_occurrence_can_be_reopened` green).
3. `async def change_time(db, occ, class_date, start: time, end: time, now) -> AttendanceSession`:
   - `end <= start` → 422. `class_date < now.date()` → 422 "That class has already passed".
   - `row` = `source="schedule"` row for `(occ.id, class_date)`.
   - no row: `scheduled_times(occ, class_date)` is None → 422 "No class is scheduled on that date; use Start now".
     Else create `AttendanceSession(status="scheduled", source="schedule", class_date, starts_at, ends_at,
     lecturer_id=occ.lecturer_id, opened_at=None)` with the new times.
   - row `scheduled` → update times. row `open` → new `ends_at <= now` → 422 "Use End now instead";
     else update times and `lecturer_action_at=now`. Other statuses → 409 "This class has already ended".
   - New times: `datetime.combine(class_date, start/end)`.
   - The job applies the change on its next tick (no opening/closing inside this call).
   - Audit `SESSION_TIME_CHANGED`, old/new `{"starts_at","ends_at"}` (old = previous row values, or the
     weekly times when the row was just created).
4. `async def cancel_class(db, occ, class_date, now) -> AttendanceSession`:
   - `class_date < now.date()` → 422. Row lookup as above; no row and not a scheduled date → 422.
   - no row → create it with `status="cancelled"` and the weekly times. Row `scheduled` → `cancelled`.
     Row `open` with **no** attendance records → `cancelled`, `closed_at=now`. Row `open` with records → 409
     "Attendance is already recorded; end the class instead". Other statuses → 409.
   - Audit `SESSION_CANCELLED`, old/new `{"status"}`.
5. `async def extend(db, session, minutes: int, now) -> AttendanceSession` — only `open` or `scheduled`
   (else 409); `ends_at += minutes`; `lecturer_action_at=now` when open. Audit `SESSION_EXTENDED`
   old/new `{"ends_at"}`. (A legacy open row with `ends_at` NULL → 409 "This session has no end time".)
6. End early = existing `PUT /lecturer/sessions/{id}/close`: keep the router, but call
   `close_session(session_id, db, now)` and also set `session.ends_at = now` (effective end). Audit
   `SESSION_ENDED`, old `{"status": "open", "ends_at"}` → new `{"status": "closed", "ends_at"}`. Still 409
   when `status == "closed"`; also 409 for `needs_confirmation`/`cancelled`/`scheduled` (message
   "Session is not open").
7. `async def confirm(db, session, held: bool, now)` — only `needs_confirmation` (else 409).
   `held=True` → remember `old = session.closed_at`, call `close_session(...)` (absents marked,
   `status="closed"`), then set `session.closed_at = old` (the end the job recorded). `held=False` → `status="cancelled"`. Audit
   `SESSION_CONFIRMED_HELD` / `SESSION_CONFIRMED_NOT_HELD`.

`session_service.close_session(session_id, db, now: datetime | None = None)`: use `now or now_myt()` for
`closed_at`. No other change to its behaviour.
