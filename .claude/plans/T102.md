## Approach
Reuses the T100/T101 endpoints and the T91 tab. The lecturer "ask" screen mirrors the student chat
(same `answer_question`), citations open a `LecturerSource` screen via the new lecturer file
endpoint. The "before next class" screen renders the cached T101 summary with `MarkdownText`.

## Edge cases
- A lecturer's citation `file_url` points at the student endpoint, so the app builds the lecturer
  URL from `material_id` instead.
- The lecturer app has no `expo-intent-launcher`, so phone "open" uses the share sheet only.
- CORS must allow :8093 or the second worktree's Playwright can't reach the API.
