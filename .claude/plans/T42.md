# T42 — Device client for Pi and webcam (FR-401, FR-409, FR-411)

## Goal
Build `backend/device_client/`, a small standalone program that runs on the Raspberry Pi (Pi camera) or on a laptop with a USB webcam (FR-409, same code, the room's device key). It:
1. sends `POST /device/heartbeat` every 20 s, always (also while idle);
2. polls the server for an open session for its room, and only opens the camera while one is open (FR-401);
3. detects faces locally with a light detector (OpenCV Haar cascade, bundled with opencv, no download, fine on a Pi);
4. crops each face with a 30 % margin, JPEG-encodes it and POSTs the crops of one frame to `POST /device/faces` with `X-Device-Key` (FR-402). The server does embedding, matching and voting (T41);
5. releases the camera when the session closes, then goes back to polling.

Run on the laptop: `cd backend && DEVICE_KEY=... python -m device_client --camera 0`.

Done when: the package exists and runs as above; unit tests for detection → crop → post with a fake camera/detector/API pass; plus one small server endpoint `GET /device/session` (needed so the client can find the session the same way `/device/faces` does) with `db` tests.

**Not in this task (decided):**
- FR-411 offline buffering ("optionally" in the Done-when, Could Have) is NOT built: replaying crops later needs the server to accept a `captured_at` and compute Late from it, which is a time-rule change. If the API is unreachable the client logs, waits 1 s and carries on (frames in that gap are dropped). Note this in PROGRESS "Next".
- `face_worker/` and `/internal/active-session|face-match|face-review` stay unchanged. Removing them deletes tests in `test_devices.py`, `test_attendance_statuses.py`, `test_char_face_review.py` and the admin face-review queue still reads `/internal/face-review` data; that removal belongs with T43 (which replaces the review queue). Only the docs change to point at the new client.

@router.get("/session", response_model=DeviceSessionOut)
async def current_session(
    camera: Camera = Depends(device_service.require_device),
    db: AsyncSession = Depends(get_db),
):
    """The open session this device records into, found exactly as POST /device/faces finds it.

    The device client polls this and opens its camera only while a session is open (FR-401).
    404 when there is none.

`backend/device_client/detector.py`:
```python
Box = tuple[int, int, int, int]   # x, y, w, h in frame pixels

class Detector(Protocol):
    def detect(self, frame: np.ndarray) -> list[Box]: ...

class HaarDetector:
    """OpenCV's bundled frontal-face Haar cascade: no model download, a few ms per frame on a Pi."""
    def __init__(self, min_face: int = 60):
        path = cv2.data.haarcascades + "haarcascade_frontalface_default.xml"
        self._cascade = cv2.CascadeClassifier(path)
        if self._cascade.empty():
            raise RuntimeError(f"Cannot load face detector {path}")
        self._min = (min_face, min_face)
    def detect(self, frame):
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        gray = cv2.equalizeHist(gray)
        found = self._cascade.detectMultiScale(gray, scaleFactor=1.1, minNeighbors=5, minSize=self._min)
        return [tuple(int(v) for v in box) for box in found]
```

`backend/device_client/crops.py`:
```python
def expand_box(box: Box, frame_w: int, frame_h: int, margin: float = 0.3) -> Box
```
- `dx = round(w * margin)`, `dy = round(h * margin)`; `x0 = max(0, x - dx)`, `y0 = max(0, y - dy)`, `x1 = min(frame_w, x + w + dx)`, `y1 = min(frame_h, y + h + dy)`; return `(x0, y0, x1 - x0, y1 - y0)`.
  Examples (tests use them): `(100,100,100,100)` in 640×480 → `(70,70,160,160)`; `(0,0,50,50)` → `(0,0,65,65)`; `(600,440,40,40)` in 640×480 → `(588,428,52,52)`.
```python
def crop_faces(frame: np.ndarray, boxes: list[Box], margin: float = 0.3,
               max_crops: int = 10, max_side: int = 320) -> list[bytes]
```
- Drop boxes with `w <= 0 or h <= 0`. Sort the rest by area `w*h`, largest first; keep the first `max_crops`.
- For each: `expand_box`, slice `frame[y:y+h, x:x+w]`; skip if empty; if `max(h, w) > max_side` resize with `cv2.INTER_AREA` so the longer side == `max_side` (keep aspect, each side ≥ 1); `ok, buf = cv2.imencode(".jpg", crop, [cv2.IMWRITE_JPEG_QUALITY, 90])`; skip if not ok; append `buf.tobytes()`.
- Never write anything to disk (NFR-01).

`backend/device_client/api.py` (sync `httpx`):
```python
class ApiError(Exception): ...
class ApiUnreachable(ApiError): ...      # connection error / timeout
class AuthError(ApiError): ...           # 401 or 403: wrong or revoked key

class DeviceApi:
    def __init__(self, base_url: str, key: str, client: httpx.Client | None = None, timeout: float = 5.0):
        self._client = client or httpx.Client(base_url=base_url, timeout=timeout)
        self._headers = {"X-Device-Key": key}
    def heartbeat(self) -> None                 # POST /device/heartbeat
    def current_session(self) -> int | None     # GET /device/session: 200 → session_id, 404 → None
    def send_faces(self, crops: list[bytes]) -> dict | None
        # POST /device/faces, files=[("crops", (f"face{i}.jpg", data, "image/jpeg")) ...]
        # 200 → resp.json(); 404 → None (session closed)
    def close(self) -> None
```
- One private `_request(method, path, **kw)` wraps `self._client.request(method, path, headers=self._headers, **kw)`; `httpx.TransportError` → `raise ApiUnreachable(str(exc)) from exc`; status 401/403 → `AuthError(f"{status}: {text[:120]}")`. Callers handle 404 themselves; any other non-2xx (e.g. 503 model not loaded, 413, 422) → `ApiError(f"{status}: {text[:120]}")`.
- When the caller passes `client`, the base URL is that client's (tests build `httpx.Client(base_url="http://test", transport=httpx.MockTransport(handler))`).

`backend/device_client/runner.py`:
```python
class CameraError(Exception): ...

class DeviceRunner:
    def __init__(self, api, open_camera: Callable[[], Any], detector, config: Config,
                 clock: Callable[[], float] = time.monotonic,
                 sleep: Callable[[float], None] = time.sleep,
                 log: Callable[[str], None] = print):
        self.running = True
        self._last_heartbeat: float | None = None
    def stop(self) -> None: self.running = False
    def tick_heartbeat(self) -> None
    def wait_for_session(self) -> int | None
    def process_frame(self, frame) -> str        # "no_face" | "sent" | "session_closed"
    def capture(self, session_id: int) -> None
    def run(self, max_sessions: int | None = None) -> None
```
- `tick_heartbeat()`: `now = clock()`; if `_last_heartbeat is None or now - _last_heartbeat >= config.heartbeat_seconds`: set `_last_heartbeat = now` FIRST, then `api.heartbeat()`; catch `AuthError` → re-raise; catch other `ApiError` → `log("[device] heartbeat failed: ...")`.
- `wait_for_session()`: `log("[device] waiting for an open session...")` once; `while self.running:` `tick_heartbeat()`; try `sid = api.current_session()`; `ApiUnreachable` → log, sid=None; (AuthError propagates; other ApiError → log, sid=None); if sid → log `"[device] session {sid} is open"` and return sid; `sleep(config.poll_seconds)`. Returns None when stopped.
- `process_frame(frame)`: `boxes = detector.detect(frame)`; none → `"no_face"`; `crops = crop_faces(frame, boxes, config.margin, config.max_crops, config.max_side)`; none → `"no_face"`; `result = api.send_faces(crops)`; `None` → `"session_closed"`; else log one line per result: `f"[device] face {r['index']}: {r['outcome']} student={r.get('student_id')} similarity={r.get('similarity')} votes={r.get('votes')}"` (never names — the server sends none); return `"sent"`.
- `capture(session_id)`:
  - `camera = open_camera()`; if `not camera.isOpened()`: `camera.release()` and raise `CameraError(f"Cannot open camera {config.camera}")`.
  - `try:` loop `while self.running:`
    - `tick_heartbeat()`; `now = clock()`
    - every `poll_seconds` (track `last_check`, start = time capture began): `try: sid = api.current_session()` except `ApiUnreachable`: keep going (treat as still open); if `sid != session_id` → log `"[device] session {session_id} closed"` and `break`.
    - `ok, frame = camera.read()`; if not ok: `failures += 1`; if `failures >= 50` raise `CameraError("Camera stopped giving frames")`; `sleep(0.1)`; continue. else `failures = 0`.
    - frame pacing: if `last_frame is not None and now - last_frame < 1 / config.fps`: continue (keep reading so the camera buffer stays fresh). Else `last_frame = now`.
    - `try: outcome = process_frame(frame)` `except ApiUnreachable as exc: log(...); sleep(1.0); continue` `except AuthError: raise` `except ApiError as exc: log(...); continue`.
    - `if outcome == "session_closed": log(...); break`.
  - `finally: camera.release()` (the camera is off whenever no session is open, FR-401).
- `run(max_sessions=None)`: `count = 0`; `while self.running:` `sid = wait_for_session()`; `if sid is None: break`; `capture(sid)`; `count += 1`; `if max_sessions is not None and count >= max_sessions: break`. `max_sessions` exists for tests.

## Traps
- `device_client` must not import `app.*` (it runs on the Pi without the backend). Tests import it as `from device_client.config import Config` etc. (pytest `pythonpath=.` is `backend/`).
- Never print or log the device key; never read `backend/.env` (CLAUDE.md: never read secrets). The old worker loaded `backend/.env` — do NOT copy that.
- No face images in tests or committed files: frames are numpy noise/zeros (CLAUDE.md, PDPA). Crops are never written to disk.
- Do not touch `face_worker/`, `/internal/*`, or their tests. Do not edit, skip or weaken any existing test.
- `httpx` sync client: `httpx.MockTransport(handler)` works with `httpx.Client(transport=..., base_url="http://test")`. `httpx.ConnectError` is a `TransportError` subclass — catch `httpx.TransportError`.
- A 404 from `/device/faces` or `/device/session` is a normal "no session" answer, not an error. 401/403 must stop the client (a revoked key will never start working).
- `tick_heartbeat` sets `_last_heartbeat` before calling the API, so a down server is not hammered every loop iteration.
- Frame pacing must not stop reading frames (stale camera buffer), only skip analysing them.
- Haar `detectMultiScale` returns an empty tuple (not an array) when nothing is found — the list comprehension handles both.
- `crop_faces` must take the largest faces first when there are more than `max_crops` (server returns 422 above 10).
- `test_device_client.py` is not a `db` test: do not add the db marker; it must run in check.sh's fast suite without docker.
