# T101 — "Before next class" summary (FR-816, NFR-09)

## Files to change
- `backend/app/services/kb/before_class.py` — new service: `before_class_summary(db, course)`.
- `backend/app/schemas/assistant.py` — `BeforeClassOut` (content, citations, not_enough_data).
- `backend/app/routers/assistant.py` — `GET /lecturer/assistant/before-class/{course_id}`.
- `backend/tests/live/test_live_qa.py` — wrap `before_class._sections_for_materials` in the
  `capture` fixture; add one live case.
- `backend/tests/test_before_class.py` — mock tests (fake LLM capturing the prompt).

## Approach
Build the summary ONLY from `trends.question_trends` aggregates (already anonymised, ≥3
students). The LLM is never handed names, chat text, or a below-minimum topic.

- "Too little data" = all three aggregate lists empty → return the fixed
  "not enough questions yet" message with `not_enough_data=True` and **no LLM call**.
- Otherwise resolve `most_cited_materials[].material_id` to *existing* material sections
  (`_sections_for_materials`: first chunk per material, so a deleted material is skipped and
  never cited), prompt the LLM for a two-part note ("## Revisit" with [n] citations +
  "## Not covered by the materials"), then map citations via the existing `parse_answer`.
- Cache in memory keyed by `course.id` → `(trends_fingerprint, result)`; a changed aggregate
  (new topic / count) regenerates, an unchanged one reuses the result. `reset_cache()` for tests.

## Edge cases
- Only off-syllabus topics (uncovered list non-empty, no sections) → still generate; sections
  text becomes "(no cited material sections remain)" and the LLM cites nothing.
- Prompt contains no student names / question text / below-3 topics (guaranteed by
  `question_trends`; pinned by a test that captures the prompt).
- Access: course lecturer or admin (`_course_for_staff`); other lecturer → 403, student → 403.
- LLM down → 503 (mirrors the other assistant endpoints).

## Tests
- `tests/test_before_class.py` (mock LLM, faked embeddings):
  - empty aggregates → "not enough questions yet", fake LLM never called;
  - with 3 students on one topic → summary cites a real section; prompt capture asserts no
    names / question text / below-minimum topic;
  - caching: second call with unchanged aggregates does not re-call the LLM; a new topic
    re-calls;
  - deleted material is never cited;
  - access control (other lecturer 403, student 403, admin 200);
  - LLM down → 503.
- Live suite: seed 3 student messages on one topic (no LLM for the questions), call
  `before_class_summary` (one LLM call), record the fixture, assert structure + real citations.
